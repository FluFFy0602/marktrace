# 32. Презентации защит: содержание по слайдам

**MarkTrace · версия 1.0 · 16.11.2026**

Содержание слайдов для защит 1–4 по дорожной карте курса. Порядок слайдов взят из примерной структуры презентации МИРЭА («Примерная структура презентации МИРЭА. Проектная деятельность»). Что требуется на каждой защите и где это лежит в репозитории, описано в [31-checkpoints.md](31-checkpoints.md).

## 0. Как устроен документ и колоды

Каждый слайд описан одинаково:

- **заголовок** — третий уровень, «Слайд N. Название»;
- **тезисы** — 3–6 пунктов списка;
- **иллюстрация** — диаграмма из `docs/diagrams/`, снимок экрана из `docs/screens/`, таблица или код. Если её нет, указано «нет»;
- **говорит** — кто выступает, затем текст на 2–3 предложения.

Колоды `docs/export/*.pptx` собраны из этого документа программой pandoc. В качестве `--reference-doc` взят шаблон, производный от примерной презентации МИРЭА: макеты переименованы так, как их ищет pandoc, синяя полоса с логотипом и титульный слайд перенесены в макеты. Правила сборки:

- если у слайда есть иллюстрация, на слайде показана только она, крупно, одна на слайд. Тезисы и текст выступающего уходят в заметки докладчика;
- если иллюстрации нет, на слайде показаны тезисы, а текст выступающего уходит в заметки;
- титульный слайд строится из списка участников.

Скрипты сборки лежат в `docs/export/tools/`. Команды для пересборки — в разделе 5.

## 5. Сборка колод

```bash
cd docs/export/tools
REF="${TMPDIR:-/tmp}/mirea-ref.pptx"
python3 build_ref.py "<путь>/Примерная_структура_презентации_МИРЭА_Проектная_деятельность.pptx" "$REF"
python3 build_decks.py ../../32-presentations.md "$REF" ..
```

`build_ref.py` строит из примерной презентации МИРЭА reference-doc для pandoc. Сама примерная презентация не меняется, reference-doc в репозиторий не кладётся. `build_decks.py` разбирает этот документ по правилам раздела 0 и вызывает `pandoc --reference-doc`. После этого он подгоняет таблицы: задаёт ширину столбцов по длине текста, высоту строк и размер шрифта. Шрифт приходится уменьшать, потому что pandoc рассчитан на слайд шириной 13,3 дюйма, а слайд шаблона МИРЭА — 26,7 дюйма. Нужен pandoc 3.x (колоды собраны версией 3.12). Снимки `docs/screens/*.png` снимаются с запущенного стека (`make up`, вход как `admin`, только просмотр); после смены оформления интерфейса их нужно переснять и пересобрать колоду 4.
