# 31. Чек-лист защит (контрольные точки 1–4)

**MarkTrace · версия 1.0 · 16.11.2026**

Чек-лист перед каждой защитой. Каждое требование дорожной карты курса (практики 1–32) привязано к файлам репозитория. Статусы проверены по содержимому файлов на 16.11.2026. Слайды по каждой защите описаны в [32-presentations.md](32-presentations.md), сценарий показа на финальной защите — в [33-demo-script.md](33-demo-script.md).

Обозначения статуса:

- **готово** — файл есть, его содержание соответствует реализации MVP;
- **готово, оговорка** — файл есть, но в нём есть расхождение с MVP, которое нужно исправить или назвать на защите (исправление указано в столбце «Примечание»);
- **заглушка [..]** — в файле остался плейсхолдер, его нужно заполнить до защиты;
- **OPEN** — артефакта нет.
